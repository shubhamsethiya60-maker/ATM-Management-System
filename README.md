# ATM Management System

## Project Description

The ATM Management System is a simple Python-based project that simulates the basic operations of an ATM.

The user can log in using an account number and PIN and can perform different banking operations such as checking balance, withdrawing money, depositing money, changing PIN and viewing a mini statement.

## Features

- Account number login
- 3 PIN attempts
- Balance enquiry
- Cash withdrawal
- Cash deposit
- PIN change
- Mini statement
- Multiple sample accounts
- Input validation
- Simple menu-driven interface

## Technologies Used

- Python 3
- No external libraries

## How to Run

1. Install Python 3.
2. Keep all four files in the same folder.
3. Open the folder in VS Code or IDLE.
4. Run `main.py`.
